# DerbySoft

> DerbySoft — "The Travel Commerce Accelerator" — is a global travel-technology company providing high-performance distribution connectivity, hotel content management, and digital-marketing services. It connects hotel suppliers, channel managers, OTAs, metasearch engines, and TMCs through standardized APIs across 500+ channels.

This llms.txt was generated by the API Evangelist enrichment pipeline from DerbySoft's public developer knowledge bases (no provider-published /llms.txt was found).

## APIs

- [Property Connector Integration API](https://pc.knowledgebase.derbysoftsec.com/en/support/solutions/articles/70000157127-api-overview): JSON/REST API to push availability, rates and inventory (ARI), manage property/room/rate/channel config, and exchange reservations. Bearer-token auth; TLS 1.2+; 15 req/sec.
- [Content Distributor API](https://contentsolutions.knowledgebase.derbysoftsec.com/en/support/solutions/articles/70000673856-content-distributor-api): OTA 2016B XML API for distributors to access hotel content (OTA_HotelSearchRQ/RS, OTA_HotelDescriptiveInfoRQ/RS).
- [Content Supplier API](https://contentsolutions.knowledgebase.derbysoftsec.com/en/support/solutions/articles/70000671527-about-content-supplier-api): API for suppliers to query and write property, guestroom, and rate-plan content.
